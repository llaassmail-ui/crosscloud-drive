# 跨域云盘 V2 用户使用手册

本手册面向使用 Windows 云电脑或普通 Windows 电脑的员工。管理员创建 OSS Bucket、RAM 用户和 AccessKey 后，用户通过跨域云盘把授权的 OSS 路径挂载为 Windows 盘符。

## 1. 使用前准备

向管理员获取：

- OSS 地域，例如新加坡。
- Bucket 名称。
- OSS 路径，例如 `/users/<user>`；`/` 表示整个 Bucket，普通员工通常不应获得此权限。
- RAM AccessKey ID 和 AccessKey Secret。

不要使用阿里云主账号 AccessKey，不要把 Secret 放进截图、聊天记录、脚本参数或公开文档。Secret 泄露后，应立即让管理员禁用旧密钥并创建新密钥。

## 2. 启动工具

工具需要整个项目目录，不能只复制 `oss-mount-gui.ps1`。双击：

```text
scripts\start-oss-mount-gui.vbs
```

`start-oss-mount-gui.vbs` 会隐藏 PowerShell 启动窗口。`start-oss-mount-gui.cmd` 仍然保留，但只建议在需要排查启动问题时使用。

也可以在 PowerShell 中启动：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\oss-mount-gui.ps1
```

工具使用 Windows PowerShell 5.1 和 WinForms，不需要安装其他语言环境。左侧底部的 `English/中文` 可即时切换界面语言。

## 3. 第一次连接

### 3.1 安装组件

在“连接”页点击“安装组件”。工具通过 winget 安装：

- rclone：负责访问和挂载 OSS。
- WinFsp：让 rclone 能在 Windows 中提供盘符。

WinFsp 安装可能触发 UAC。安装完成但工具仍显示未安装时，关闭并重新打开工具；极少数情况下需要注销或重启 Windows。

### 3.2 填写设置

进入“设置”页：

| 字段 | 说明 |
|---|---|
| 地域 | 选择 Bucket 所在地域；常用 Endpoint 会自动填写 |
| Endpoint | 仅在选择“自定义”时手动填写主机名 |
| Bucket | 必填，默认留空，不要在开头添加 `/` |
| 远端目录 | 默认 `/`；`/users/<user>` 表示只挂载该前缀 |
| AccessKey ID | 管理员提供的 RAM AccessKey ID |
| AccessKey Secret | 第一次配置必填，默认隐藏，可勾选“显示”检查 |
| 盘符 | 建议“自动选择”，也可以选 D 到 Z 的空闲盘符 |
| 缓存上限 | 默认 `5G`，可选 `10G`、`20G` 或输入自定义值，最小 `1G` |
| 登录时自动挂载 | 默认开启 |
| 自动恢复 | 默认开启，每 5 分钟进行一次隐藏的本地检查 |

缓存建议：

- `5G`：办公文档和较小系统盘。
- `10G`：一般文件使用。
- `20G`：经常处理大文件，并且系统盘空间充足。

缓存上限是 rclone 的清理目标，不是严格配额。正在上传或仍被占用的缓存文件可能让实际占用短时间超过设置值。

### 3.3 测试并连接

1. 点击“仅测试”。
2. 成功后点击“保存并连接”。
3. 返回“连接”页，等待盘符出现。
4. 点击“打开云盘”或在文件资源管理器中打开对应盘符。

测试与连接期间，相关按钮会暂时禁用，防止重复启动。

## 4. 日常使用

“连接”页显示当前远端路径、Endpoint、最近检查时间和组件状态。“活动”页可以筛选全部、错误、挂载和上传记录，并可以打开日志目录或复制脱敏诊断信息。

### 停止

“停止”只断开本次登录中的挂载，并保留连接、登录任务和自动恢复配置。手动停止后，本次登录不会被 5 分钟恢复任务重新拉起；下次登录 Windows 时会恢复挂载。

### 重新连接

“重新连接”重新测试当前配置、清除本次登录的暂停标记并再次挂载。

### 移除此设备上的连接

该操作会清理本工具管理的本机任务、目标 rclone 挂载进程、盘符记录、rclone remote、状态文件、启动文件和默认缓存。可以在第二次确认中选择是否同时卸载 rclone 和 WinFsp。

无论是否卸载依赖，都不会删除 OSS 云端文件。自定义到工具目录以外的缓存不会被自动递归删除。

## 5. 常见问题

### 为什么盘符显示为“网络位置”？

工具使用 rclone 的网络模式，这是预期行为。它更符合对象存储的语义，不影响常规浏览、复制、保存和删除。

### 在文件资源管理器删除后，OSS 控制台为什么还看到文件？

先等待目录缓存刷新，并确认删除发生在挂载盘符内。随后检查：

- Bucket 是否开启版本控制。删除当前版本后，历史版本或删除标记仍可能存在并继续产生存储费用。
- OSS 控制台是否正在显示“历史版本”。
- 看见的是不是 0 字节目录标记。OSS 没有真正的文件夹，目录只是对象名前缀。
- 上传是否仍在缓存中重试。磁盘满、权限不足或 Endpoint 错误都可能阻止同步。

不要为了排障使用不受限制的云端批量删除命令。需要清理历史版本时，由管理员在 OSS 控制台使用版本管理或生命周期规则处理。

### 每五分钟为什么会有检查？

自动恢复任务每 5 分钟检查一次盘符和本工具对应的 rclone 进程。正常连接存在时不会启动第二个进程。任务通过隐藏的 `wscript.exe` 启动器运行，正常情况下不应出现命令行窗口。

如果仍有窗口闪现，让管理员在任务计划程序中检查任务动作是否指向 `%LOCALAPPDATA%\CrossCloudDrive\runtime\MountWorker.vbs`，并移除旧版本遗留任务。

### 磁盘满了会怎样？

rclone 的完整 VFS 缓存需要本地磁盘。系统盘满时可能出现保存失败、上传失败、反复重试或应用卡住。释放空间后再重新连接，并在活动页或 `mount.log` 查看错误。

### 文件时间和时区能修改吗？

OSS 服务端时间使用 UTC；Windows 文件资源管理器通常按本地时区显示。工具保留对象修改时间，不会关闭 modtime。OSS 控制台和 Windows 的显示格式可能不同，但不代表文件内容被改动。

### 云电脑休眠、断开或重新登录后会怎样？

- 只是断开远程会话：云电脑和 rclone 通常继续运行。
- 休眠或网络短暂中断：恢复后 rclone 可能自行恢复；自动恢复任务会定期检查。
- 注销、重启或重新开机：登录任务会重新挂载。
- 云电脑被管理员还原或重置：本机配置可能丢失，需要重新配置。

具体休眠和还原行为取决于云电脑策略，不由 OSS 或本工具决定。

### AccessKey Secret 为什么重新打开后是空的？

工具自己的状态 JSON 不保存 Secret。首次配置时，Secret 由 rclone 保存到当前 Windows 用户的配置中；后续仅修改非凭据设置时可以复用已有 remote。若 AccessKey 已轮换，请输入新的 ID 和 Secret 并重新连接。

### OSS 完全托管密钥有什么作用？下载文件仍是加密的吗？

OSS 完全托管密钥是服务端静态加密：对象写入 OSS 后由 OSS 加密保存，读取时由 OSS 自动解密并通过 HTTPS 传输。用户正常下载或通过挂载打开时得到的是原始文件内容，不是不可读的密文。它保护的是 OSS 介质上的静态数据，不能替代 RAM 权限、HTTPS、终端安全或客户端自行加密。

## 6. 费用说明

rclone 和 WinFsp 本身不收 OSS 使用费。常见费用来自：

- 存储容量和存储时长。
- PUT、GET、LIST、DELETE、分片上传等请求次数。
- OSS 到云电脑的公网或跨地域出流量。
- 版本控制保留的历史版本和未完成分片。

同地域不一定自动等于免费内网流量，取决于实际 Endpoint、网络产品和阿里云国际站计费规则。价格会随地域、存储类型和时间变化，应以阿里云国际站 OSS 定价页和账单为准。建议配置预算告警、版本生命周期和未完成分片清理规则。

## 7. 本地文件位置

V2 本地状态默认位于：

```text
%LOCALAPPDATA%\CrossCloudDrive
```

主要内容包括连接状态、语言设置、隐藏启动文件、缓存和日志。状态文件不包含 AccessKey Secret；rclone 凭据由当前 Windows 用户的 rclone 配置管理。
