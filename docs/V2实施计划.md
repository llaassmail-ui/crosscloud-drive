# 实施计划：跨域云盘 V2

状态：实施中；核心代码、自动化测试、双语文档和发布安全复核已完成，真实 Windows 桌面验收与发布目录改名待执行

## 1. 概述

在保留现有阿里云 OSS 挂载、RAM 批量创建和完整本机移除能力的基础上，将当前单文件 WinForms 工具重构为可维护的模块化应用。V2 首期只交付阿里云国际版 OSS，提供中文/英文 GUI、每用户单连接、5 GB 默认 VFS 缓存、隐藏登录挂载与 5 分钟自动恢复，并兼容清理 V1 遗留内容。

实施采用增量替换：先建立可测试的状态、Provider 和命令契约，再接入任务与卸载，最后替换 GUI。任何阶段都不得通过复制当前脚本形成第二套挂载逻辑。

## 2. 架构决策

- 产品标识：显示名称使用“跨域云盘 / CrossCloud Drive”；内部稳定标识使用 `CrossCloudDrive`。
- Provider 边界：通用模块只认识统一连接模型；阿里云的 Endpoint、Bucket 校验和 rclone S3 参数位于 `AlibabaOss.Provider.ps1`。
- 单连接范围：每个 Windows 用户只保存一个本工具连接；非目标 rclone 任务和进程不得被接管。
- 凭据：Secret 仅写入 rclone 配置，不写入工具状态 JSON、日志或诊断信息。
- 后台运行：登录挂载和 watchdog 均通过隐藏 VBS 启动器执行，不显示 PowerShell 窗口。
- 兼容策略：识别并迁移或清理 `%LOCALAPPDATA%\rclone\oss-mount` 和旧任务名；V2 数据写入 `%LOCALAPPDATA%\CrossCloudDrive`。
- GUI：固定左侧导航，右侧为连接、设置、活动三个页面；使用同一控件树即时切换语言。
- 测试：核心逻辑不依赖真实 OSS；通过 PowerShell AST 检查、轻量断言测试和伪 rclone 集成测试验证。

## 3. 依赖顺序

```text
状态与本地化契约
        |
        +--> 阿里云 Provider --> 通用 rclone 核心
                                  |
                                  +--> 计划任务与 watchdog
                                  |
                                  +--> 停止、移除与 V1 迁移
                                              |
                                              +--> 双语 GUI
                                                      |
                                                      +--> CLI、文档与发布检查
```

## 5. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| WinForms 在高 DPI 下布局错位 | 高 | 使用固定导航宽度、表格布局、AutoScaleMode 和三档 DPI 截图验收 |
| 计划任务每 5 分钟闪窗或重复挂载 | 高 | 强制 VBS 隐藏启动，并同时检查目标盘符和经过严格匹配的进程 |
| V1 清理误伤其他 rclone | 高 | 使用任务动作、remote、盘符和命令行多条件匹配；测试非目标样本 |
| rclone 缓存超过设置值 | 中 | 默认 5 GB、显示磁盘警告，并在文档中说明上限不是硬配额 |
| AccessKey 出现在日志或状态文件 | 高 | Secret 只传给 rclone 配置命令，诊断统一脱敏并做静态扫描 |
| Provider 抽象过度设计 | 中 | V2 只定义满足 OSS 的最小接口，不提前实现 S3/GCS 特有功能 |
| GUI 与 CLI 行为再次分叉 | 中 | 两个入口都调用同一个 Core、State、Tasks 和 Provider 模块 |

## 6. 本计划不包含

- V2 首期不实现 Amazon S3、S3 兼容存储或 Google Cloud Storage。
- 不实现同一 Windows 用户的多连接或多盘符列表。
- 不把 RAM 用户创建放入普通用户 GUI。
- 不引入 Python、Node.js、Electron 或第三方 PowerShell 模块。
- 不自动删除用户选择的自定义缓存目录。
