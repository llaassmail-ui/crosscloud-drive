# 规格：跨域云盘 V2（首期阿里云 OSS）

状态：已确认；核心实现、自动化验证和发布安全复核已完成，真实 Windows 桌面验收与发布目录改名待执行

本文档是 V2 优化的需求与验收依据。产品中文显示名称为“跨域云盘”，英文显示名称为 `CrossCloud Drive`，公开仓库建议名称为 `crosscloud-drive`。

## 1. 当前假设

1. V2 首期只交付阿里云国际版 OSS，但产品后续可能增加 Amazon S3、S3 兼容存储或 Google Cloud Storage；核心代码和本地状态模型必须保持云厂商无关。
2. 目标设备是阿里云无影云电脑和普通 Windows 10/11 电脑。
3. 继续使用 Windows PowerShell 5.1、WinForms、rclone 和 WinFsp，不引入 Python、Node.js 或额外桌面运行时。
4. 普通员工的主要任务是首次配置、查看状态、打开云盘和处理故障，不需要看到复杂运维参数。
5. RAM 用户与策略的批量创建仍由管理员脚本负责，不放进普通用户 GUI。
6. 现有完整卸载能力、RAM 最小权限模型和公开仓库安全要求必须保留。
7. V2 可以调整本地配置文件和计划任务结构，但必须兼容清理 V1 遗留内容。
8. V2 GUI 必须同时提供简体中文和英文，并使用同一套功能与布局。
9. V2 首期在同一 Windows 用户下只管理一个云存储连接；这不限制该电脑上的其他 Windows 用户或其他软件运行自己的 rclone 进程。
10. 现有目录名在开发期间可以暂时保留；公开发布前再将仓库目录统一改为 `crosscloud-drive`，避免在重构过程中同时引入大量无行为价值的路径改名。

## 2. 目标

### 2.1 产品目标

构建一个可扩展的云对象存储 Windows 挂载客户端。V2 首期以阿里云国际版 OSS 作为第一个 Provider，使非技术员工可以完成以下工作：

- 输入管理员提供的 Bucket、目录和 AccessKey。
- 从地域列表选择 OSS Endpoint。
- 测试权限并挂载为 Windows 盘符。
- 登录 Windows 后自动恢复挂载。
- 清楚看到连接状态、缓存占用和最近错误。
- 停止挂载或完整移除本机连接，不影响 OSS 云端文件。

管理员应能继续通过 CLI 批量创建 RAM 用户、最小权限策略和 AccessKey。

### 2.2 设计目标

V2 GUI 必须形成独立的视觉和交互结构，不再沿用当前版本及下载版共同使用的“顶部大标题 + 中间表单卡片 + 底部常驻日志框”布局。

目标风格：安静、清晰、偏 Windows 系统工具，适合员工每天查看和重复操作；不做营销页，不使用装饰性渐变、光球或大面积品牌色。

### 2.3 非目标

- 不把 OSS 伪装成具备完整 POSIX/NTFS 语义的本地磁盘。
- 不实现 OSS Bucket 管理、生命周期配置或版本恢复控制台。
- 不保存阿里云主账号密码。
- 不在 V2 首期实现 Amazon S3、其他 S3 兼容存储或 Google Cloud Storage，但不得把 OSS 专属字段和命令散落在 GUI、任务或通用状态模块中。
- 不在普通用户 GUI 中创建或修改 RAM 策略。
- 不在 V2 首期支持同一 Windows 用户同时管理多个云存储连接。

“单连接”具体指：当前 Windows 用户的工具配置中只有一个受管理的 Provider、Bucket/容器、远端目录和盘符组合。该连接正常挂载时通常对应一个 `rclone mount` 进程。工具不得阻止、结束或接管其他 Windows 用户、其他程序或用户手动启动的非目标 rclone 进程。

## 3. 用户与核心流程

### 3.1 普通员工

首次使用：

1. 双击启动工具。
2. 工具检查 rclone 和 WinFsp。
3. 缺失依赖时，用户点击“安装组件”；只有 WinFsp 安装触发 UAC。
4. 用户选择地域，填写 Bucket、OSS 目录、AccessKey ID 和 Secret。
5. 用户点击“测试并连接”。
6. 测试成功后自动选择可用盘符、创建隐藏的登录任务并挂载。
7. 界面进入“已连接”状态，用户可以打开云盘或退出工具。

日常使用：

1. Windows 登录后自动挂载。
2. 打开工具即可看到当前盘符、远端路径、缓存占用和最近检查时间。
3. 挂载异常时可以点击“重新连接”。

离职或设备交还：

1. 点击“移除此设备上的连接”。
2. 明确选择是否保留 rclone 和 WinFsp。
3. 工具删除任务、挂载进程、盘符记录、remote 凭据、启动文件和默认缓存。
4. 工具不得删除 OSS 云端对象。

### 3.2 管理员

1. 使用 `create-oss-ram-users.ps1` 批量创建 RAM 用户和策略。
2. Bucket 必须显式传入，不允许包含真实项目默认值。
3. 普通员工使用前缀权限；管理员/NAS 账号使用“全桶对象读写”权限。
4. AccessKey CSV 必须被 `.gitignore` 排除，并在输出中提示安全删除。

## 4. GUI 重设计

### 4.1 信息架构

使用固定左侧导航和右侧工作区，窗口建议尺寸为 `960 x 640`，最小尺寸为 `820 x 560`。

左侧导航固定宽度 `176px`：

- `连接`：默认页面，展示状态和主要操作。
- `设置`：OSS 连接、凭据、盘符、缓存和自动恢复设置。
- `活动`：运行日志、最近错误和诊断信息。
- 底部：中文/English 语言切换、版本号。

右侧工作区使用全宽分区和细分隔线，不把整个页面包进大卡片，也不嵌套卡片。

### 4.2 连接页面

已连接状态：


连接页面不显示 AccessKey，不常驻显示完整日志。

### 4.3 设置页面

按纵向分区排列，不使用八个输入框同时平铺：

`存储位置`

- 地域：下拉菜单，默认新加坡。
- Endpoint：根据地域自动填写；选择“自定义”后才可编辑。
- Bucket：必填，默认空。
- OSS 目录：默认 `/`，输入时规范化为无首尾斜杠的前缀。

`身份凭据`

- AccessKey ID：必填。
- AccessKey Secret：密码框，默认隐藏。
- “显示”使用眼睛图标或复选框，不使用普通文字按钮。
- 重新打开工具时不从工具自己的 JSON 回填 Secret；凭据由 rclone 配置管理。

`本机挂载`

- 盘符：默认“自动选择”；高级用户可以手动选择空闲盘符。
- 缓存上限：下拉选择 `5 GB / 10 GB / 20 GB / 自定义`，默认 `5 GB`。
- 缓存选项下方显示系统盘剩余空间和动态提示：`5 GB` 适合办公文档和较小系统盘；`10 GB` 适合一般文件使用；`20 GB` 适合频繁处理大文件且磁盘空间充足的设备。
- 自定义缓存必须大于等于 `1 GB`。当配置值超过当前可用空间的 25%，或系统盘剩余空间低于 `10 GB` 时显示警告，但不在未说明原因的情况下静默修改用户设置。
- 提示用户：`--vfs-cache-max-size` 是 rclone 的清理目标，不是严格磁盘配额；正在上传和仍被占用的文件可能令实际缓存短时间超过配置值。
- 自动恢复：开关，默认开启。
- 登录时自动挂载：开关，默认开启。

底部固定操作栏：

- 主按钮：`测试并连接`
- 次按钮：`仅测试`
- 危险操作不放在这里；完整移除放在页面底部的“设备连接”分区。

### 4.4 活动页面

- 顶部提供状态筛选：`全部 / 错误 / 挂载 / 上传`。
- 日志列表按时间倒序展示，使用等宽字体显示详情。
- 提供“打开日志目录”和“复制诊断信息”命令。
- 默认最多加载最后 500 行，避免大日志拖慢 GUI。
- AccessKey ID、Secret 和签名参数不得出现在诊断信息中。

### 4.5 视觉规范

- 页面背景：`#F6F8FA`
- 导航背景：`#FFFFFF`
- 主文字：`#1F2328`
- 次文字：`#59636E`
- 主操作蓝：`#0969DA`
- 成功绿：`#1A7F5A`
- 警告黄：`#9A6700`
- 危险红：`#CF222E`
- 边框：`#D0D7DE`
- 圆角：`4px` 或 `6px`，不得超过 `8px`
- 字体：优先 `Segoe UI`，中文回退 `Microsoft YaHei UI`
- 页面标题 `20px`，分区标题 `14px`，正文 `12px`；不使用随窗口宽度缩放的字体。
- 不使用渐变、大面积深蓝背景、装饰性插画或嵌套卡片。
- 所有固定控件必须设置明确宽高，125%、150%、175% DPI 下文字不得被截断或重叠。

### 4.6 状态模型

GUI 只允许以下连接状态：

```text
Unconfigured -> Checking -> Connecting -> Connected
                        \-> Failed
Connected -> Reconnecting -> Connected
                       \-> Failed
Connected -> Stopped
Any -> Removing -> Unconfigured
```

按钮可用性必须由状态统一控制，防止用户在连接过程中重复点击安装、连接或移除。

### 4.7 多语言规则

- GUI 必须提供简体中文和英文两套本地化字典，控件代码中不得散落直接显示给用户的硬编码文本。
- 首次启动根据 Windows UI 语言选择：中文 UI 使用简体中文，其他语言使用英文；语言检测失败时确定性回退为简体中文。
- 用户可以在 GUI 左侧导航底部切换 `中文 / English`，切换后当前窗口立即刷新，不要求重启工具。
- 用户选择的语言作为非敏感本机设置保存，后续启动优先使用该设置。
- 所有工具生成的控件文字、对话框、连接状态、校验错误、卸载确认、诊断摘要、通知和空状态都必须本地化。
- `OSS`、`rclone`、`WinFsp`、`Bucket`、`Endpoint`、`AccessKey ID` 等技术名称允许保持原文；不得出现缺少翻译键导致的键名、空白文字或无意义的中英文混排。
- 原始第三方命令输出可以保留原语言，但 GUI 必须为失败结果提供当前界面的本地化摘要。
- 中英文使用同一套布局；控件尺寸按较长语言文本设计，不能依靠缩小字体解决英文截断问题。

## 5. 功能优化范围

### 5.1 必须实现

1. 将 GUI、挂载核心、计划任务和本地状态读写拆分为独立脚本模块。
2. Bucket 为空时阻止连接，并校验阿里云 OSS Bucket 命名规则。
3. OSS 目录统一规范化，GUI 中 `/` 代表挂载整个 Bucket。
4. 自动选择空闲盘符，允许高级用户覆盖。
5. 移除 `--no-modtime`，保留对象修改时间显示。
6. 增加 `--vfs-cache-max-size`，默认 `5G`，可选择 `5G / 10G / 20G / 自定义`。
7. 目录缓存默认 `1m`，高级设置允许 `30s / 1m / 5m`。
8. 保存非敏感连接信息，但不在工具 JSON 中保存 AccessKey Secret。
9. 登录自动挂载任务必须使用 `wscript.exe` 隐藏启动，并设置任务为隐藏。
10. 增加可关闭的自动恢复任务，默认每 5 分钟检查一次。
11. 自动恢复只在目标盘符不存在且对应 rclone mount 进程不存在时启动。
12. 完整卸载必须清理 V1/V2 任务、进程、盘符记录、remote、启动文件和默认缓存。
13. 停止进程必须同时验证进程名、`mount` 命令和目标盘符/remote，不得只按历史 PID 强制终止。
14. 工具必须明确区分“停止挂载”和“移除此设备上的连接”。
15. 任何本地移除操作都不得调用 OSS 对象删除命令。
16. GUI 必须完整支持简体中文和英文，并可在不重启工具的情况下即时切换。
17. 必须提供中文和英文的项目说明、用户手册与管理员部署指南；中文规格文档继续作为 V2 需求的权威来源。
18. Provider 专属的字段定义、输入校验、rclone remote 参数和测试逻辑必须位于独立 Provider 模块；GUI、计划任务和通用状态模块只消费统一的连接模型。
19. 普通用户 GUI 保留“完整卸载 rclone 和 WinFsp”选项，放入二次确认对话框，并明确说明不会删除云端文件。

### 5.2 建议实现

- 内置阿里云国际版常用地域 Endpoint 列表，并保留自定义 Endpoint。
- 显示 rclone、WinFsp 版本和安装状态。
- 显示默认缓存目录当前占用和配置上限。
- 日志轮转：单文件达到 `5 MB` 后保留最近 3 份。
- 提供“复制诊断信息”，包含版本、Endpoint、盘符、任务状态和脱敏错误。
- 首次成功挂载后提供“打开云盘”，不强制立即关闭工具。

### 5.3 后续版本候选

- Windows 网络恢复事件触发重连，减少固定轮询。
- Amazon S3、其他 S3 兼容存储和 Google Cloud Storage Provider。
- 多连接、多 Bucket 或多盘符管理。
- AccessKey 轮换向导。
- 可选的 rclone 配置加密。

## 7. 命令

启动 GUI：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\oss-mount-gui.ps1
```

PowerShell 语法检查：

```powershell
$files = Get-ChildItem .\scripts\*.ps1
foreach ($file in $files) {
    $tokens = $null
    $errors = $null
    [System.Management.Automation.Language.Parser]::ParseFile(
        $file.FullName,
        [ref]$tokens,
        [ref]$errors
    ) | Out-Null
    if ($errors.Count) { throw "$($file.Name): $($errors[0].Message)" }
}
```

创建普通 RAM 用户：

```powershell
.\scripts\create-oss-ram-users.ps1 `
    -Bucket "example-workspace" `
    -Usernames alice,bob `
    -CreateAccessKey
```

创建全桶对象读写账号：

```powershell
.\scripts\create-oss-ram-users.ps1 `
    -Bucket "example-workspace" `
    -Usernames nas-admin `
    -PolicyMode FullBucket `
    -CreateAccessKey
```

公开发布前扫描：

```powershell
git diff --cached
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Test-ReleaseReadiness.ps1
```

发布检查脚本会跳过二进制和常见运行时文件，并扫描真实凭据、真实 Bucket、真实人员路径、内部路径和 AI 工具痕迹。扫描结果出现真实凭据、真实 Bucket、真实人员路径或内部信息时，必须在发布前清理。

## 9. 代码风格

- 函数使用批准的 PowerShell 动词和 `PascalCase`，例如 `Get-OssMountState`。
- 局部变量使用 `camelCase`，脚本级状态使用 `$script:` 前缀。
- 外部命令必须检查退出码并返回结构化结果。
- 删除文件前必须解析绝对路径并验证位于工具拥有的目录中。
- 用户输入先规范化，再校验，最后传给 rclone。
- GUI 事件处理器只组织流程，不直接拼接长命令或执行递归删除。

示例：

```powershell
function Normalize-OssPrefix {
    param([AllowEmptyString()][string]$Prefix)

    $normalized = $Prefix.Trim().Trim("/")
    if ($normalized -match '(^|/)\.\.(/|$)') {
        throw "OSS path cannot contain '..'."
    }
    return $normalized
}

function New-MountArguments {
    param(
        [Parameter(Mandatory = $true)][string]$Remote,
        [Parameter(Mandatory = $true)][string]$MountPoint,
        [Parameter(Mandatory = $true)][string]$CacheDir,
        [ValidatePattern('^\d+[KMGT]$')][string]$CacheMaxSize = "5G"
    )

    return @(
        "mount", $Remote, $MountPoint,
        "--network-mode",
        "--vfs-cache-mode", "full",
        "--vfs-cache-max-size", $CacheMaxSize,
        "--dir-cache-time", "1m",
        "--cache-dir", $CacheDir
    )
}
```

## 11. 边界

### Always：始终执行

- 使用 RAM 子账号和最小权限。
- Bucket 默认为空，OSS 目录默认 `/`。
- 安装与挂载前验证输入和依赖。
- 计划任务使用隐藏 VBS 启动器。
- 修改挂载参数后同步更新文档。
- 完整移除前明确说明不会删除云端文件。
- 发布前执行凭据和私密信息扫描。

### Ask first：需要先确认

- 增加 AWS、其他 S3 或多连接支持。
- 引入新的运行时、第三方 PowerShell 模块或打包框架。
- 改变 RAM 权限范围。
- 默认启用 rclone 配置加密。
- 删除用户选择的自定义缓存目录。
- 修改 AccessKey 的创建、轮换或停用流程。

### Never：绝不执行

- 提交真实 Bucket、AccessKey、员工姓名或内部截图。
- 使用阿里云主账号 AccessKey。
- 卸载时调用 `rclone delete`、`purge` 或 OSS 删除 API。
- 只根据旧 PID 终止进程。
- 对未经边界验证的路径执行递归删除。
- 静默安装或卸载需要管理员权限的软件。
- 将 AccessKey Secret 写入日志、诊断信息或工具自己的 JSON。

## 12. 成功标准

### 功能

- 新用户在一个窗口内最多经过 3 个主要动作完成挂载：安装组件、填写配置、测试并连接。
- Bucket 为空或格式错误时，rclone 不会被调用。
- OSS 目录 `/` 能正确挂载整个 Bucket，`users/<user>` 能正确挂载指定前缀。
- 目标盘符占用时自动选择其他盘符，不覆盖现有盘符。
- 登录 Windows 后能隐藏恢复挂载，不出现命令行闪窗。
- watchdog 连续执行 3 次时，不会为正常连接创建重复 rclone 进程。
- 默认 VFS 缓存上限为 5 GB，GUI 可选择 5 GB、10 GB、20 GB 或自定义值。
- GUI 显示缓存配置建议和系统盘剩余空间；空间偏低或配置比例过高时给出明确警告。
- Windows 文件管理器显示对象修改时间，不再强制禁用 modtime。

### 卸载与安全

- “停止”保留自动挂载配置；下次登录可以恢复。
- “移除此设备上的连接”清理 V1/V2 任务、目标进程、盘符记录、remote、工具启动文件和默认缓存。
- 保留依赖模式不会卸载 rclone 或 WinFsp。
- 完整卸载模式需要再次确认后才卸载依赖。
- 两种移除模式均不改变 OSS 云端对象数量。
- 非目标 rclone 任务和非目标 rclone 进程不会被删除或终止。
- 仓库扫描不包含真实凭据和真实 Bucket 默认值。

### GUI

- GUI 与当前版本及下载版在首屏结构上明显不同：左侧导航、独立连接页、设置页和活动页。
- 连接页不出现 AccessKey 输入框和常驻日志框。
- 100%、150%、175% DPI 下无文字截断、控件重叠或按钮尺寸跳动。
- 危险操作使用红色并与日常连接操作分离。
- 键盘 Tab 顺序符合视觉顺序，密码显示开关可访问。
- 简体中文和英文可以在当前窗口即时切换，连接状态和已填写的表单值不会丢失。
- 两套语言字典的键集合完全一致，不出现缺失翻译键、键名直接显示或空白文字。
- 除约定保留原文的技术名称和第三方原始输出外，任何页面不得出现无意义的中英文混排。
- 中文和英文界面在 100%、150%、175% DPI 下均无文字截断、控件重叠或横向滚动条。

### 质量

- 所有 PowerShell 文件语法检查通过。
- 核心规范化、参数生成、任务识别、进程识别和安全删除测试通过。
- 中英文 README、用户手册和管理员指南与 V2 GUI、任务名称及卸载行为一致。

## 13. 风险与约束

- WinForms 的响应式布局能力有限，必须使用锚定、自动缩放和最小尺寸约束控制 DPI 问题。
- OSS 不是本地文件系统，文件锁、随机写入、原子重命名和空目录行为仍可能与 NTFS 不同。
- `--vfs-cache-mode full` 依赖本地磁盘；缓存上限不能保证系统盘在其他程序占满时仍可写入。
- 每 5 分钟 watchdog 会产生本地任务活动，但正常情况下不应产生 OSS 请求或可见窗口。
- `--vfs-cache-max-size` 不是严格磁盘配额；待上传或正在使用的缓存文件可能使实际占用短时间超过设置值。
- rclone 配置默认包含可恢复的 AccessKey 凭据；V2 首期仍依赖 Windows 用户隔离和文件 ACL。
- 自动清理旧任务必须足够精确，不能误删用户自己创建的其他 rclone 任务。

## 14. 已确认决策

1. 中文产品名称使用“跨域云盘”，英文产品名称使用 `CrossCloud Drive`，公开仓库建议名称使用 `crosscloud-drive`。
2. V2 首期每个 Windows 用户只由本工具管理一个连接；整台电脑可以存在其他用户或其他软件管理的 rclone 进程。
3. 自动恢复默认每 5 分钟检查一次，任务和启动器必须隐藏运行。
4. VFS 缓存默认 5 GB，提供 5 GB、10 GB、20 GB 和自定义选项，并显示容量建议与磁盘空间警告。
5. 普通用户 GUI 保留完整卸载 rclone 和 WinFsp 的入口，必须二次确认。
6. V2 GUI 必须支持简体中文和英文即时切换。
7. V2 首期只实现阿里云国际版 OSS，但通用核心和本地状态模型必须为后续 S3/GCS Provider 保持可扩展。
